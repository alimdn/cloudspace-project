# Weekly Performance Report Template

## Report Structure

Every weekly report follows this five-part structure:
1. Summary Metrics Dashboard
2. Content Performance Breakdown
3. Best Performing Content Analysis
4. Weak Content Diagnosis
5. Next Week Recommendations

## Part 4: Weak Content Diagnosis

For the bottom 2-3 performing pieces, diagnose the specific failure point.

### Three-Part Failure Framework

| Failure Type | Definition | Evidence Pattern | Common Causes |
|-------------|------------|-----------------|---------------|
| Hook Failure | Content did not capture attention | Impressions OK, retention/view duration < 15% | Slow opening, generic statement, no visual contrast |
| Value Failure | Captured attention but didn't deliver value | High views, low saves/shares/comments | Too promotional, no actionable content, clickbait disconnect |
| Conversion Failure | Generated engagement but didn't drive action | Good engagement, CTR < 1% | Unclear CTA, weak offer, price barrier, no urgency |

### Diagnosis Template (per weak piece)

**Content**: [Title/Description]
**Failure Type**: [Hook / Value / Conversion]
**Evidence**: [Specific metric that indicates failure, e.g., "2,400 views but only 12 clicks (0.5% CTR)"]
**Root Cause Hypothesis**: [Most likely specific cause, e.g., "CTA was buried at the end of a 45-second video without text overlay"]
**Recommended Fix**: [Specific, testable improvement, e.g., "Move CTA to the 30-second mark with bold text overlay and a 20% discount code"]
**Test Plan**: [How to validate the fix, e.g., "Reshoot with new CTA placement, A/B test against original next week"]

## Part 5: Next Week Recommendations

3-5 SMART recommendations based on this week's data.

### SMART Format

For each recommendation:
- **Action**: What specifically to do
- **Rationale**: Why, based on this week's data (reference specific metrics)
- **Expected Impact**: What metric should improve and by approximately how much
- **Owner**: Who is responsible
- **Deadline**: When it should be completed
- **Measurement**: How success will be evaluated in next week's report

### Recommendation Template

```
RECOMMENDATION [N]:
Action: [Specific action]
Rationale: [Data-based reasoning with specific metric references]
Expected Impact: [Metric] should improve by [X%] within [timeframe]
Owner: [Name/Role]
Deadline: [Day, Date]
Measurement: [How to verify in next week's report]
```

### Common Recommendation Categories

1. **Double down on winners**: Replicate top performer format across more products
2. **Fix diagnosed failures**: Implement recommended fixes from weak content analysis
3. **Test new approaches**: Try a content format or platform not yet tested
4. **Optimize timing**: Shift posts to better time slots based on this week's data
5. **Adjust offer**: Modify pricing, bonuses, or guarantees based on conversion data
6. **Expand distribution**: Add a new channel based on performance gaps
7. **Content recycling**: Update and republish high-performing content from previous weeks

---

## Report Quality Checklist

Before delivering the report, verify:
- [ ] All metrics include week-over-week comparison (not just raw numbers)
- [ ] Top performer analysis explains WHY, not just WHAT
- [ ] Weak content uses the three-part failure framework (not vague criticism)
- [ ] Recommendations reference specific data from this week's report
- [ ] Each recommendation is specific enough to execute without clarification
- [ ] No fabricated data — all unknowns use [XX] placeholder format
- [ ] The "Key Insight" in Part 1 genuinely captures the most important trend
